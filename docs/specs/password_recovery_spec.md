# パスワード変更・再設定仕様

## ログイン中の変更

- ダッシュボードの「パスワード変更」から実行する。
- 現在のパスワードで再認証してから変更する。
- 新しいパスワードは10文字以上とする。
- 変更後はログインCookieを削除し、新しいパスワードで再ログインする。
- 管理者を含め、利用者が変更できるのは自分自身のパスワードだけとする。

## パスワードを忘れた場合

1. ログイン画面の「パスワードを忘れた方」を開く。
2. 登録メールアドレスを入力する。
3. Supabase Authがパスワード変更用URLをメールで送信する。
4. 利用者がURLを開き、新しいパスワードを2回入力する。
5. Supabase Authのリカバリーセッションで本人確認後、パスワードを更新する。
6. 更新後はログイン画面へ戻り、新しいパスワードでログインする。

## セキュリティ要件

- メールアドレスが登録済みかどうかを送信画面に表示しない。
- リカバリーURLの有効性・有効期限はSupabase Authで検証する。
- Secret Keyおよびパスワードをブラウザ、ログ、DBの独自テーブルへ保存しない。
- 本番URLと `/reset-password` をSupabase Authの許可URLに登録する。
- メール送信回数はSupabase Authのレート制限に従う。
